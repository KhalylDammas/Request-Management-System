# Request Management System

## 1. What the application does

A Python terminal application for creating and viewing requests. New requests are saved with a unique ID and status New.

The user can :
Create request
view requests
Exit the application

## 2. How to create the database and table

The database and table can be created using the database.sql file

The database name is RequestDB

The table name is Requests

## 3. How to configure the SQL Server connection
The SQL Server connection settings are in request.py

## 4. How to run the application
Run the following command in the terminal:
python request.py

## 5. Where requests are stored
Requests are stored in the Requests table in RequestDB
